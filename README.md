このリポジトリは、書籍『textlint入門 基礎からカスタマイズまで』のサンプルコードを公開しています。

書籍とサンプルコードの対応関係は次のようになっています。

| 本書   | サンプルコードのパス（リポジトリルートを基準） |
| :----- | :--------------------------------------------- |
| 章     | `chapter{章}`                                  |
| 節     | `chapter{章}/{節}_*`                           |
| コラム | `chapter{章}/{節}_column_*`                    |
